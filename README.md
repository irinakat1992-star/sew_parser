Автор: Михеева Ирина Олеговна

*Парсер для сбора информации о товарах с сайта* `https://sew-irk.ru/`

Парсер выполняет следующие задачи:

1. Обходит защиту Cloudflare
2. Собирает названия и цены товаров из указанного раздела
3. Обрабатывает пагинацию (переход по всем страницам)
4. Сохраняет данные в различных форматах (Excel, CSV, JSON)

Можно указать любой раздел с сайта `https://sew-irk.ru/` и собрать по нему необходимую информацию о товарах и ценах.

**Структура проекта:**

Корневые файлы:

- sew-parser.py – Основной файл парсера
- README.md – документация проекта,
- .gitignore – игнорируемые файлы для Git,
- requirements – список зависимостей.

В директории output находятся  файлы с результатами.
